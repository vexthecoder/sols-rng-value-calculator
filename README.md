# Sol's RNG Value Calculator

A simple inventory value calculator for Sol's RNG.


## Features

- Updated for Era 9
- Multi Add
- Settings (Settings Save)
- - GIF Toggle
- - Light and Dark Themes
- Aura/Category Searching
